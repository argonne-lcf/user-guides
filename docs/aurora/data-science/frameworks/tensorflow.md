# TensorFlow on Aurora

As of `frameworks/2026.1.0` (PE 26.181.0), `TensorFlow` is no longer part of the compute image on Aurora. If users are interested in using it on Aurora, please contact [support@alcf.anl.gov](mailto:support@alcf.anl.gov).
